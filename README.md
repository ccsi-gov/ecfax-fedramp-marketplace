Fedramp Marketplace Schema for ECFax

## Service Overview
ECFax<sup>®</sup> (powered by eFax<sup>®</sup>) is a unified, secure, cloud-native Software as a Service (SaaS) managed solution and document exchange platform purpose-built for Federal and State Agencies, government contractors and software vendors subject to FedRAMP<sup>®</sup> security standards. Developed with a human-centered design for secure government cloud environments, ECFax<sup>®</sup> serves as an all-in-one cloud service that modernizes manual or semi-automated faxing processes and eliminates the need for multiple fax vendors and numerous costly contracts.

Unlike hybrid infrastructure (IaaS) middleware or legacy on-premise servers that demand heavy configuration, constant IT oversight, and expensive analog/T1 phone lines, ECFax<sup>®</sup> is a complete SaaS solution, offering a 'set it and forget it,' low-maintenance architecture. ECFax<sup>®</sup> provides a seamless cloud migration path for agencies and governmental organizations transitioning away from legacy environments or on premise multifunctional or fax devices. It integrates smoothly with existing enterprise applications, dramatically reducing the Total Cost of Ownership (TCO) and ensuring compliance with Agency policies.

### Key Features & Delivery Methods:
- ECFax Portal: A unified application providing secure environment access. It features a User Administrative Portal for daily tasks and Tenant Level Elevated Permissions for localized management, utilizing role-aware architecture to ensure a secure, scalable experience.
- Email to Fax: Secured through TLS encryption for protected message transfer between servers
- ECFax API: RESTful fax API integration for enterprise applications and programs
- Shared folders, distribution lists, and inboxes for multi-endpoint digital delivery
- ECFax Messenger: Windows desktop application with print-to-fax functionality, compatible with any application that has a print function (i.e. Outlook, Word, Excel, PDF and PowerPoint. Additional licensing applies)
- Multi-Function Devices (MFDs): Scan and fax via ECFax’s high-security process with integrated authentication, contacts, and cover pages (some functionality may require API integration)

**Enterprise & System Integrations:**

- Productivity & Workspace Platforms: Integration capabilities with Microsoft 365 (including Outlook and SharePoint), Google Workspace, print/output management software, and electronic health record (EHR) systems.
- Automated Inbound Data Ingestion: ECFax’s RESTful API enables seamless inbound data feeds directly into agency workflows and enterprise systems including ServiceNow, Salesforce, Microsoft SharePoint, Document Management Systems (DMS), Palantir and other AI-driven analytics platforms.

**ECFax Offers:**

- Scalability: Hosted on Amazon Web Services GovCloud, ECFax<sup>®</sup> scales on-demand to millions of pages per month through auto-scaling and elastic load balancing. Agencies can transition from legacy fax servers to the cloud without a costly end-to-end replacement. ECFax® integrates with existing infrastructure while modernizing the underlying platform.
- Efficiency: Cloud fax significantly reduces overhead expenses. Workflow automation and digital intake automation reduce labor costs and optimize processes while ensuring compliance with all Federal guidelines and policies.
- Security: ECFax<sup>®</sup> is FedRAMP<sup>®</sup> Class D (High) Certified and HIPAA compliant, providing secure data transfer for PHI/PII with FIPS 140-2cc validated cryptographic modules and TLS encryption for data in transit. All data is hosted in AWS GovCloud’s isolated infrastructure, designed to meet the highest security standards required by government agencies.
- 24/7 Support: State-of-the-art help desk support to ensure agencies get responsive service around the clock, minimizing operational disruptions and maintaining mission-critical continuity.
- Management & Porting: The ability to port and assign DIDs to meet the customers workload and business practices.
